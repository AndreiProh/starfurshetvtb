# Заказы продуктов — Flask

Небольшой сайт каталога с заказами без регистрации покупателей, SQLite и закрытой панелью администратора.

## Требования
- Python 3.10+
- pip

## Запуск на Windows
Откройте PowerShell в папке проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Создайте хеш пароля администратора:

```powershell
python -c "from werkzeug.security import generate_password_hash; print(generate_password_hash('ЗАМЕНИТЕ_НА_СВОЙ_ПАРОЛЬ'))"
```

Скопируйте `.env.example` в `.env` и заполните значения. Flask сам по себе не читает `.env`, поэтому переменные нужно задать в PowerShell перед запуском:

```powershell
$env:SECRET_KEY = "длинная-случайная-строка"
$env:ADMIN_USERNAME = "admin"
$env:ADMIN_PASSWORD_HASH = "вставьте-хеш-из-команды"
python app.py
```

Для локального запуска сайт откроется по адресу http://127.0.0.1:5000, вход администратора — http://127.0.0.1:5000/admin/login.

## Настройка каталога
Редактируйте `products.json`. Каждая позиция имеет поля:
- `id` — уникальный постоянный идентификатор латиницей;
- `name` — название;
- `price` — цена числом;
- `category` — категория;
- `unit` — единица измерения;
- `description` — описание;
- `active` — необязательное поле; `false` скрывает товар.

Не меняйте `id` уже существующих товаров без необходимости: он используется в истории заказов.

Цены в примере демонстрационные — замените их на реальные. Перед запуском проверьте валюту и правила доставки.

## Размещение в интернете
Проект можно развернуть на Python-хостинге, поддерживающем Gunicorn. Настройте переменные окружения `SECRET_KEY`, `ADMIN_USERNAME`, `ADMIN_PASSWORD_HASH`, `DATABASE_PATH` и `CATALOG_PATH`.

**Важно:** файловая SQLite-база подходит для небольшого магазина при условии постоянного дискового хранилища. Убедитесь, что хостинг сохраняет файл базы между перезапусками и не запускает несколько независимых копий приложения с разными локальными базами. Для масштабирования используйте PostgreSQL. HTTPS должен быть включён на хостинге.

## Уведомления
Панель администратора автоматически опрашивает сервер примерно каждые 10 секунд и показывает уведомление о новом заказе, пока страница панели открыта. Это не push-уведомление и не сработает, если панель закрыта. Telegram/email-уведомления можно подключить отдельно.

## Перед реальным запуском
- заменить демонстрационные товары и цены;
- установить сильный `SECRET_KEY` и пароль администратора;
- включить HTTPS;
- настроить резервное копирование базы;
- проверить условия доставки, минимальный заказ и валюту;
- при публичном запуске добавить ограничение частоты запросов и полноценную защиту от CSRF, например Flask-WTF;
- разместить политику обработки персональных данных, соответствующую юрисдикции бизнеса.
